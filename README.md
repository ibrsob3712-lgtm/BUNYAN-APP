# BUNYAN v1.2 – Field Professional

Professional Flutter platform for documenting inspections of existing buildings and supporting qualified engineers in organizing defects, photos, measurements, tests and assessment priorities.

## Key production improvements
- Modularization pathway from the earlier monolithic application.
- Offline-first local data persistence.
- Field inspection and defect workflow.
- Local image documentation.
- Transparent prioritization logic.
- Reporting and backup foundations.
- Test foundations and production-readiness documentation.

## Build commands
```bash
flutter create .
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

The application is a documentation and decision-support tool and does not independently issue structural safety certificates.
