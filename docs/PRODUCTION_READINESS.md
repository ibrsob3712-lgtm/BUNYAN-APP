# BUNYAN v1.1 – Production Readiness Plan

## Completed in this package
- Functional offline-first local SQLite data model.
- Projects, buildings, floors and structural elements.
- Inspection sessions and defect registration.
- Local image capture and measurement storage.
- Test-record registry.
- Transparent prioritization engine.
- PDF summary generation.
- Production-oriented modular architecture roadmap.
- Validation and error-handling foundations.

## Mandatory before commercial deployment
1. Run static analysis and Flutter tests.
2. Perform physical-device testing on multiple Android versions.
3. Add a signed release keystore.
4. Replace development-only report text with approved organization templates.
5. Add encrypted export/import backup workflow.
6. Add integration tests for data-loss scenarios.
7. Have engineering assessment rules reviewed and approved by qualified specialists.
8. Perform privacy/security review before cloud synchronization is introduced.
