## Production hardening checklist
Before commercial deployment, run:
1. flutter analyze
2. flutter test
3. Physical-device testing on supported Android versions
4. Database persistence/restart testing
5. Camera permission testing
6. Signed APK/AAB release testing

## Professional limitation
The assessment engine is decision support. It must not independently certify structural safety or replace a qualified engineer's judgment.
